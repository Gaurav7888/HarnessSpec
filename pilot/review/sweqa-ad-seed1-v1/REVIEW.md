# Independent SWE-QA answer review

Use only the supplied packet, grade template, and pinned source repositories during scoring. Please record whether you have already seen the candidates, experiment results, or condition-to-answer mapping. A reviewer with prior exposure should disclose it to the study coordinator before scoring. The coordinator records reviewer identity or pseudonym, independence, date, and rubric version separately from the grade JSON.

1. Open `packet.json`. Each opaque `grading_id` identifies one original question, candidate answer and citations. The reference answer, evidence paths/ranges, repository and commit are supplied for checking. Preserve the IDs and candidate wording.
2. Read the entire question and answer. Check material claims against the release's reference and the source at the specified commit. Cite a path and line in the rationale when an evidence error or disagreement with the reference affects the score. Filename overlap alone is insufficient to judge the explanation.
3. In a copy of `grade_template.json`, give **five independent integer scores from 0 to 10** for each answer. Judge **correctness** by factual accuracy, **completeness** by coverage of the question, **relevance** by focus on the question, **clarity** by intelligibility, and **reasoning** by the soundness of the code-grounded explanation. Give a short, nonempty rationale that explains material strengths, omissions, or factual errors. The template's nulls mean ungraded.
4. The total is twice the sum of the five scores. A total of at least 70 passes. Totals from 50 to 69 are partial, and totals below 50 fail. Only a pass counts as resolved. Apply these thresholds consistently. This study uses human application of the repository-QA study's rubric. Use your own judgment and record any adjudication before seeing condition information. [Published study and Appendix D](https://arxiv.org/html/2608.01507v1#A4)
5. Return the completed JSON and the separate provenance note to the coordinator. Preserve the original review and any later adjudication as separate versions. Do not add a numerical total, reviewer metadata or a pass boolean inside a grade object. The importer calculates the outcome.
